# Examples

The repository includes complete ROS 2 packages:

| Package | Demonstrates |
| --- | --- |
| [example](https://github.com/PickNikRobotics/generate_parameter_library/tree/main/example) | C++ generation, validators, parameter updates, and tests |
| [example_external](https://github.com/PickNikRobotics/generate_parameter_library/tree/main/example_external) | Consuming a generated C++ library from another package |
| [example_python](https://github.com/PickNikRobotics/generate_parameter_library/tree/main/example_python) | Python generation using setuptools |
| [example_cmake_python](https://github.com/PickNikRobotics/generate_parameter_library/tree/main/example_cmake_python) | Python generation using CMake |

Each package's README includes build and run commands. The `config` directories contain runtime parameter files, including examples with missing required parameters.
